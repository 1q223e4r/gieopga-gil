# 기업가의 길

땅을 사고 통행료를 받는 경제 보드게임 「기업가의 길」의 휴대폰용 웹 게임이에요.
폰 한 대를 돌려 가며 하거나 컴퓨터와 2~4명이 함께 할 수 있어요.

**▶ 플레이: https://1q223e4r.github.io/gieopga-gil/**

## 고친 파일을 다시 올릴 때

저장소에서 **Add file → Upload files**로 바뀐 파일을 같은 이름으로 올리면 덮어써져요. 1~2분 뒤 사이트에 반영돼요.

## 폰에 앱처럼 설치하기

- 아이폰(Safari): 공유 버튼 → **홈 화면에 추가**
- 안드로이드(Chrome): 메뉴(⋮) → **앱 설치** 또는 **홈 화면에 추가**

한 번 열어 두면 인터넷이 없어도 실행돼요. 진행 중인 게임은 그 폰의 브라우저에 자동 저장돼요.

## 파일 설명

| 파일 | 내용 |
|---|---|
| index.html | 게임 전체 (화면·규칙·컴퓨터 상대) |
| sw.js | 오프라인 실행용 |
| manifest.webmanifest | 홈 화면 앱 설정 |
| icon-*.png, apple-touch-icon.png, favicon.svg | 아이콘 |
| og-image.png | 카톡 등에 링크를 보낼 때 뜨는 미리보기 이미지 |
